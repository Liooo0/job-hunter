# datasets/public —— 已声明的公开数据集

**本目录的政策（写进 SECURITY.md，改动需 review）**

本目录下的内容**允许随公开仓库发布**，前提是同时满足：

1. 数据来源本身是**公开信息**（如公开招聘信息），或**完全合成**；
2. **不含**任何个人数据：姓名、手机号、身份证、邮箱、地址、对话原文；
3. **不含**敏感商业信息：报价、合同、客户名单、内部流程原话；
4. 新增文件必须在 PR 说明里写明「数据来源」与「为何可公开」。

## 为什么单独开这个命名空间

`data/` 是 2026-09-15 泄露事故的敏感数据主来源（`data/reply_pending.json` 含真实 HR
对话、被追踪并推送到公开仓库）。为了不再出现「看到一个 .json 不知道它属于哪一类」，
公开物一律迁到这里，`data/` 整体按**私有运行数据**处理（闸门 L1 直接 deny）。
