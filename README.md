# Job Hunter — AI 辅助的求职投递工作流

> 与其广撒网，不如精准慢投：让 AI 读你的简历，只投匹配的岗位，并记录每一步的成败。

这是一个 [Claude Code](https://claude.com/claude-code) 的 **skill**：读取简历、记住求职方向与底线，在招聘平台上完成「JD 解析 → 规则过滤 → 匹配打分 → 投递 → 失败追踪 → 数据复盘」的闭环。

**设计原则：自动化提质，不追求量。** 匹配交给确定性的规则引擎，决策权始终在你手里。

## 工作流

```
简历 → 技能关键词抽取 → 每个 JD 命中加分 / 命中排除词归零
     → 达到分数线才投 → 每步动作落日志 → 失败原因入库
     → 仪表盘复盘：什么岗位/城市/简历版本有效
```

- **JD 解析**：结构化解出岗位与关键词，评估依据可解释
- **规则打分**：技能词命中 +5（封顶 30）· 目标岗位 +30 · 加权词 +10 · 排除词归零；纯 Python 规则，不走 LLM，0 token 成本
- **失败追踪**：投递 → 简历被拒 → 已读不回等 9 个阶段 × 23 种失败原因枚举入库，支持三线简历版本对比（A/B 实验）
- **数据复盘**：全部记录进 SQLite，由 [jobintel-dashboard](https://github.com/Liooo0/jobintel-dashboard) 只读可视化，回答「哪些岗位值得投」

## 它不做什么

- ❌ 不伪造简历、不代写求职信
- ❌ 不追求速度与规模——动作频率贴近人工，单账号低频使用，遵守平台规则
- ❌ 不帮你面试——投递后的一切沟通由你自己完成

## 安装

### 1. 放到 Claude Code skills 目录

```bash
git clone https://github.com/<your>/job-hunter.git ~/.claude/skills/job-hunter
```

### 2. 安装依赖

```bash
pip install DrissionPage
```

### 3. 启动远程调试的 Chrome

```bash
# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --user-data-dir=/tmp/chrome-debug

# Windows
"C:\Program Files\Google\Chrome\Application\chrome.exe" ^
  --remote-debugging-port=9222 ^
  --user-data-dir=C:\temp\chrome-debug

# Linux
google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/chrome-debug
```

在这个 Chrome 里登录 Boss / 鱼泡。

### 4. 准备简历

把你的简历丢到任意位置（支持 `.md` / `.txt`；PDF 请先转文本）：

```bash
cp ~/Documents/my-resume.md ~/.claude/skills/job-hunter/resume.md
```

## 使用

在 Claude Code 里说一句触发词就行：

```
帮我投简历
自动投递
job-hunter
```

**首次运行**，Claude 会：
1. 问你简历路径、期望岗位方向、要排除的岗位词
2. 读简历、抽技能、生成打招呼话术
3. 写入 `config.json`，展示给你确认

**后续运行**，直接问 "岗位 / 城市 / 数量 / 平台"，然后开始投。

## 手动运行（不走 Claude）

```bash
cd ~/.claude/skills/job-hunter

# 鱼泡（支持 50+ 城市）
python3 yupao_apply.py --job "产品经理实习" --city 深圳 --count 20

# Boss 直聘
python3 boss_apply.py --job "产品经理" --city 深圳 --count 20

# 关掉评分过滤，全投
python3 yupao_apply.py --job "Java实习" --city 北京 --count 20 --min-score 0
```

## 配置说明

首次引导后会生成 `config.json`，字段含义：

| 字段 | 作用 |
|------|------|
| `resume_path` | 简历文件路径 |
| `greeting` | 打招呼话术（目前仅存储，脚本默认走平台沟通流程） |
| `skills` | 你的技能词 → JD 每命中一个 +5 分，封顶 +30 |
| `target_roles` | 期望岗位 → 标题命中 +30 分 |
| `exclude_keywords` | 排除词 → 命中直接归零（如 "总监"、"架构师"） |
| `boost_keywords` | 加权词 → JD 命中 +10 分（AI/LLM 等） |
| `min_score` | 最低投递分，默认 60 |
| `default_count` | 默认投递数量（上限内低频使用） |

随时手改 `config.json` 即可调整权重。

## Token 消耗预估

| 阶段 | Tokens |
|------|--------|
| 首次引导（读简历 + 抽技能 + 生成话术） | ~6K |
| 每次启动投递（读 config + 运行脚本 + 汇报结果） | ~3K |
| 本地评分匹配 | **0**（纯 Python 规则，不走 LLM） |

投 100 份岗位的总成本 ≈ 读简历一次（一次性） + 3K 启动。**不按岗位数量线性增长。**

## 平台支持

| 平台 | 投递方式 | 城市 | 前置要求 |
|------|---------|------|---------|
| Boss 直聘 | "立即沟通" | 9 大城市 + 全国 | 登录 |
| 鱼泡直聘 | "发送简历"优先，降级"聊一聊" | 50+ 城市 | 登录 |
| 前程无忧 51job | 搜索页内联"投递"按钮 | 北京/上海/广州/深圳/杭州 | **登录 + 完善 51job 在线简历**（必须有在线简历，否则投递会被踢回简历向导页） |

**51job 特别说明**：
- 跳转到 `yingjiesheng.com`（应届生求职网）的校招岗位会被**自动跳过**
- 首屏卡片因 Vue 懒加载有时首次点击失败，已加重试，但仍可能需要多遍历几张卡片

## 安全与伦理

- 脚本只在你**本地浏览器**运行，简历不上传任何第三方
- 投递动作是**真实点击**，和你手工操作等价；速度贴近人工，单账号使用
- 日志与数据库保存在本地（`.gitignore`），不外传
- API 密钥、账号信息均不入库

## 岗位评估框架

投递前先用五维度打分，避免"入职当天就想走"。此框架源自 [ai-job-search](https://github.com/MadsLorentzen/ai-job-search) 的 job-evaluation 体系，针对国内求职场景调整了权重。

### 打分维度

| 维度 | 权重 | 测什么 |
|------|:---:|--------|
| **1. 技术匹配** | 30% | JD 要求的技术栈 vs 你会的 |
| **2. 职业方向** | 30% | 这个岗位是否推进你的长期目标 |
| **3. 经验匹配** | 15% | JD 要的经验类型/年限 vs 你做过的 |
| **4. 文化匹配** | 15% | 公司风格 vs 你偏好（大厂流程 vs 初创自由） |
| **5. 地点与通勤** | 10% | 深圳/远程通过，跨省搬家标记 |

### 评分标准

| 分数 | 含义 |
|:---:|------|
| 80-100 | 核心要求即你的主力技能，基本零差距 |
| 60-79 | 大部分匹配，1-2 个可学习弥补的缺口 |
| 40-59 | 部分匹配，需要明显提升 |
| 0-39 | 根本性错配 |

**地点**不参与加权，改为通过/不通过：通勤可接受或远程 = 通过；需跨省搬家 = 标记，单独讨论。

### 阈值

| 总分 | 结论 |
|:---:|------|
| 75+ | **全力投** — 定制简历和招呼语 |
| 60-74 | **可以投** — 在招呼语里主动回应短板 |
| 45-59 | **斟酌** — 除非有特殊战略价值 |
| 30-44 | **大概率跳过** |
| <30 | **直接弃** |

### 使用方式

对着 JD 走一遍这个模板：

```markdown
## 岗位评估：[公司名] - [岗位名]

### 门槛检查
- [ ] 地点 OK？
- [ ] 薪资范围在底线以上？

### 1. 技术匹配 __/100 (×0.3 = ___)
JD 核心要求：
1. ___________ → 我做过 ___________
2. ___________ → 我做过 ___________
3. ___________ → ⚠️ 没做过，但 _________

### 2. 职业方向 __/100 (×0.3 = ___)
- 岗位方向：___________
- 我长期想做：___________
- 一致程度：___________

### 3. 经验匹配 __/100 (×0.15 = ___)
JD 要求：___________
我的经验：___________

### 4. 文化匹配 __/100 (×0.15 = ___)
查到的东西（脉脉/知乎/LinkedIn）：___________
信号：🟢 / 🟡 / 🔴

### 5. 地点 ___
通勤/远程/需搬家

---
总分：___ / 100
结论：[ ] 全力投 [ ] 可以投 [ ] 跳过
```
